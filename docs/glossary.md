# Glossary / Γλωσσάριο

The shared English-Greek glossary of the nilware.io repositories.

**Usage rule.** When Claude speaks to the owner it always uses the Greek rendering, in λόγια δημοτική. Code, commit messages and pull request descriptions stay in English.

**Κανόνας χρήσης.** Όταν ο Claude μιλά στον ιδιοκτήτη, χρησιμοποιεί πάντα την ελληνική απόδοση, σε λόγια δημοτική. Ο κώδικας, τα μηνύματα των υποβολών (commits) και οι περιγραφές των αιτημάτων συγχώνευσης (pull requests) μένουν στα αγγλικά.

### Distinctions / Διακρίσεις

- **Σύνοδος** είναι η σύνοδος πράκτορα (agent session, όπως μια σύνοδος του Claude Code). **Συνεδρία σύνδεσης** είναι η σύνδεση (login session) που μένει ανοιχτή όσο γίνονται πράξεις.
- «Συνδεδεμένη συνεδρία», όχι «συνδεδεμένος χρήστης»: δεν υπάρχει πάντα χρήστης.
- Το timeout δεν είναι λήξη: **υπέρβαση χρονικού ορίου** είναι το γεγονός, **χρονικό όριο** η ρύθμιση· **λήξη συνεδρίας** είναι κάτι άλλο (session expiry).
